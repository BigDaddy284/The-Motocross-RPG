Open your map files

Click Open folder… and pick one of these folders:

  • the-motocross-rpg/public to edit the game maps exactly as the game loads them, with their tiles and the building library (best).
  • the-motocross-rpg/public/assets works for the maps and tiles, but not the buildings.
  • The shared art folder to edit the Tiled source maps (.tmj) that npm run import-art bakes into the game.
  • The whole repo folder also works; node_modules is skipped where the browser allows it.

In Chrome or Edge, Save writes straight back into the folder. In other browsers, Save downloads the file for you to copy into place.

Map editor help

  • Pan: drag with the right or middle mouse button, hold Space and drag, or use the Pan tool. Zoom: mouse wheel (zooms where the pointer is), + -, 0 fits the map.
  • Brush B, Eraser E: click or drag. Shift+drag paints or clears a rectangle.
  • Picker I: click a tile to make it the brush, or drag over several to copy a stamp. Holding Alt with the Brush picks too.
  • Fill F: floods connected matching tiles; stays inside the selection when there is one.
  • Select M: drag a box. Drag inside it to move it, Alt+drag to move a copy. Ctrl+C/X/V copy, cut and paste (click to place). Del clears. Swap with… exchanges two regions. Esc cancels.
  • Objects V: click a prop or marker to select it, drag to move (snaps to the grid; hold Alt for pixels), Del deletes a prop. With a prop picked in the palette, click empty ground to place it on the active props layer. Buildings and their doors move together: click one and use Move, or the Select tool.
  • Tabs: Map edits the map; Tiles draws and changes tiles (saved to public/assets/custom/tiles and added to the palette); Buildings edits the building library, with pictures you draw or import. With npm run dev and Load the game maps from this server, Save writes straight into the game.
  • New map… copies the open area map's ground, collision, props and spawns into a new map and adds it to the game. Check files (also run on opening) finds map files that aren't in the game's map list, listed maps whose file is gone, and building pictures not in the library, and offers to fix each.
  • Markers: pick Spawn, Exit, Door, Block zone, Gate, Travel, Venue, NPC or Interact on the left and click the map (drag for an area). Set it up on the right: where an exit leads, the flag that lifts a block zone and the tile drawn when it's cleared, and so on. Click a marker with Objects (V) to change it, drag to move it, Del deletes it.
  • Tiles tab: Pencil P, Eraser E, Fill F, Picker I (or Alt+click), Line L, Box R (Shift fills). Seams brings a tile's edges to the middle to fix how it joins itself. Ctrl+S saves the tile.
  • Buildings: pick one from the list and Place it: it follows the pointer, green where it fits and red with the reason where it doesn't; click to set it down, Esc cancels. Placing writes its pictures, doors, returns and solid tiles. Click a placed building to Move, Replace or Remove it (Del). Edit and New open it in the Buildings tab: its footprint (any size or shape), its pictures (draw one, import a PNG, or edit one), its doors and returns and its interior. They are saved in public/data/buildings.json; open the repo folder (or public) so the editor can find it.
  • Region scope: "All layers" moves tiles, collision, props, markers and partitions together. Copies never duplicate markers (doors, spawns), and Clear never deletes them.
  • Collision: make Collision the active layer; Brush blocks a tile, Eraser frees it.
  • Layers: click a layer to edit it, the eye hides it, the slider sets its opacity. [ ] step through layers, G grid, C collision overlay.
  • Save Ctrl+S. Undo Ctrl+Z, Redo Ctrl+Y.

Game maps (public/assets/maps/*.json) are rebuilt from the Tiled maps whenever someone runs npm run import-art, so edit the .tmj source for changes that should last, then re-import. After saving a game map, run npm test to check doors, spawns and NPCs still work.
