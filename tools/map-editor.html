Map editor help

  • Pan: drag with the right or middle mouse button, hold Space and drag, or use the Pan tool. Zoom: mouse wheel (zooms where the pointer is), + -, 0 fits the map.
  • Brush B, Eraser E: click or drag. Shift+drag paints or clears a rectangle.
  • Picker I: click a tile to make it the brush, or drag over several to copy a stamp. Holding Alt with the Brush picks too.
  • Fill F: floods connected matching tiles; stays inside the selection when there is one.
  • Select M: drag a box. Drag inside it to move it, Alt+drag to move a copy. Ctrl+C/X/V copy, cut and paste (click to place). Del clears. Swap with… exchanges two regions. Esc cancels.
  • Objects V: click a prop or marker to select it, drag to move (snaps to the grid; hold Alt for pixels), Del deletes a prop. With a prop picked in the palette, click empty ground to place it on the active props layer. Buildings and their doors only move together, with the Select tool.
  • Region scope: "All layers" moves tiles, collision, props, markers and partitions together. Copies never duplicate markers (doors, spawns), and Clear never deletes them.
  • Collision: make Collision the active layer; Brush blocks a tile, Eraser frees it.
  • Layers: click a layer to edit it, the eye hides it, the slider sets its opacity. [ ] step through layers, G grid, C collision overlay.
  • Save Ctrl+S. Undo Ctrl+Z, Redo Ctrl+Y.

Game maps (public/assets/maps/*.json) are rebuilt from the Tiled maps whenever someone runs npm run import-art, so edit the .tmj source for changes that should last, then re-import. After saving a game map, run npm test to check doors, spawns and NPCs still work.
